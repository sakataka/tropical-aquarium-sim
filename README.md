# 熱帯魚アクアリウム

架空の展示館「水の生き物館」（仮称）の館内図から展示室と水槽を選び、リアル寄りの熱帯魚と一枚絵の水景を眺める、個人向けのWebアクアリウムです。飼育ゲームではなく、魚種固有の自然な泳ぎ、手動照明、環境音、観賞モードを中心にしています。展示館への移行の方針は [水の生き物館 設計](docs/museum-architecture.md) にあります。

Demo: https://sakataka.github.io/tropical-aquarium-sim/

## 開発

```bash
bun install
bun run dev
bun run test          # 全テスト（約30秒）。作業中は bun run test:fast（約6秒）
bun run build
bun run verify:webview
```

画面の準備と切り替えは `src/App.tsx`、URL・ブラウザ履歴・起動時の保存データの復元は `src/navigation.ts`、水槽画面と設定パネルの開閉は `src/ui/TankScreen.tsx`、環境音の再生は `src/audio/useAmbientSound.ts` にあります。水槽画面の全画面操作も `TankScreen.tsx` で扱います。

## 画面と機能

起動すると館内図が開きます。館は本館・海の館・川と湖の館の3つの建物からなり、見出しの下の切り替えで建物を選びます。館内図は2段です。1段目は選んだ建物の断面図（本館は地上4階・地下2階）と、各階のテーマと展示室の名前を並べたフロアガイドで、階を選びます。2段目はその階の展示室の一覧で、開いている展示室には画面の縮小版が映ります（今の水景を反映）。カードを選んで展示室に入ります（まだない展示室は「準備中」）。上の階の切り替えで、同じ建物の隣の階へ移れます。今、開いているのは本館の18室・84水槽・379の生き物で、海の館と川と湖の館は準備中です。前回見ていた展示室には目印が付き、1段目から直接戻れます。展示室の左上の「館内図」か Esc で、その展示室の階の一覧へ戻ります（展示室ごとに最後に見ていた水槽を覚えます）。階の一覧の Esc で、その建物の1段目へ戻ります。

展示室の水槽を選ぶと（狭い画面では画面下の目録からも選べます）カメラが寄り、そのまま水槽を眺める鑑賞モードへ入ります。部屋のガラス越しに見えていたのと同じ切り取り方で、余白を残して全体が映ります（縦長の画面では最初から少し寄せ、左右はスワイプで見ます）。

- 拡大と見回し: ホイール・ピンチ・`+`/`-`・ダブルクリック・右下のボタンで近づき、`0` か中央のボタンで全体に戻ります。近づいたらドラッグや矢印キーで見回します。
- ガラスを叩く: 水槽を軽くクリック・タップすると、ガラスを指先で叩いたことになります。近くの魚は驚いて逃げ、住みかを持つ魚は住みか（クマノミはイソギンチャク、ハタタテハゼは巣穴）へ、物陰に隠れる魚は物陰へ飛び込み、エビは尾を打って後ろへ跳ねます。群れは間隔を詰めてまとまります。続けて叩くと慣れて反応が弱まり、しばらくすると戻ります。
- 隣の水槽へ: 上の中央の「‹ 02 / 05 ›」か `[` / `]` キーで、部屋に戻らず同じ部屋の隣の水槽へ移ります。
- 展示ラベル: 左下に水槽名・水景・照明・匹数と、いま水槽にいる生き物の名前を出します。操作しないと消えます。
- 設定: 「設定」で操作パネルを開きます（縦長の狭い画面では下から、横向きのスマホでは右から）。× か Esc で閉じます。
- 戻る: 「展示室に戻る」か Esc で引いて展示室へ戻ります。全画面表示に対応したブラウザでは「全画面」ボタンも出ます。
- 音: 右上の波形のボタンで、水の環境音と効果音をまとめて入れ・切りします（毎回OFFで始まります）。

設定パネルのタブは次の3つです。保存は自動で、保存できなかったときだけ知らせます。

- 「生き物」: その水槽に入れられる魚やエビの匹数を、種類ごと・水槽全体の上限の範囲で変えます。
- 「水景」: その水槽用の一枚絵水景から選びます。
- 「照明と音」: 自然光・クール・夕景・夜景の手動照明と、環境音の音量を設定します。

水槽は、サイズ・水景・入れられる魚種が決まった型です。

## データとアセット

魚・水景・水槽・展示室は `src/content/` にファイルを置くと自動で読み込みます。追加の手順は [開発方向性](docs/development-directions.md#魚水景水槽展示室を足すときの手順) にあります。

- `fish/<species-id>/species.json`: 学名、原産地、体長、泳層、生態プロファイル（`ecology`）、泳ぎ方（`swim`）、出典
- `fish/<species-id>/body.webp`: 描画用の横向きの魚画像（頭が左。体だけを切り出した最大幅720px）。原画はこのリポジトリに入れず、保管庫（`sakataka/aquarium-assets`）に置く。新しい種は `scripts/install-vault-species.py` で保管庫から取り込む。古い35種の原画は保管庫の `consumer/app-originals/fish/<species-id>/side.png` にあり、差し替えるときは `scripts/install-fish-sprite.py <species-id> <PNG>` と `scripts/build-fish-sprites.py <species-id>` を使う（どちらも `AQUARIUM_ASSET_VAULT` に保管庫のパスを入れる）
- `tanks/<tank-id>/tank.json`: 名前、展示ラベル用の英字名（`exhibitName`）、分類、サイズ、使える水景、入れられる魚種と上限、最初の魚
- `museum/museum.json`: 館の名前と紹介文
- `museum/buildings/<建物>/building.json` と同じフォルダの `section.webp`: 建物（並び順、名前、紹介文、断面図の絵）と、階の一覧（上からの並び順、「1階」「地下1階」などの表示、英字名、テーマの説明、断面図の絵の中の範囲）と、各階に並ぶ展示室の枠（準備中の枠も含む）。フォルダを足せば建物が増える
- `room/*.json` と同じフォルダの `.webp`: 展示室のID（`building.json` の枠の `id` と同じ）・並び順・見出し（`displayName`）・短い名前（`shortName`）・一枚絵（`image`）と、各水槽のガラスの位置。描画時にガラスをマスクで抜き、実際の水景と魚を合成する
- `environment/scenes/<scene-id>/plate.webp`: 画像生成した一枚絵の水景
- `environment/scenes/<scene-id>/scene.json`: 水景名、標準照明、水の色、寄り道先（`structurePoints`）と泡の出る位置（`bubbleSources`）、地形（`terrain`）。座標はすべて背景画像に対する0〜1の比率。地形は奥行き `depth` を持つ表面経路、奥行き別の遮蔽領域（同じ画像の該当部分をマスクで重ね、魚の前後関係を作る）、岩や流木の回避領域、隠れ場所（`shelters`。`kind` に `anemone` / `burrow` / `crevice` / `cave` を付けると住みかになる）
- `sfx.json` と `public/sfx/`: 効果音の注文書と、SFX Forge で作った効果音一式。作り直すときは `bun run --cwd /Users/sakataka/Documents/sfx-forge sfx build "$PWD/sfx.json" --out "$PWD/public/sfx"`。「設定を開く」は「閉じる」を少し高く鳴らして使い、ガラスを叩く音は「ボタン」（厚いガラスを軽く叩く音）を使う。素材の作者とライセンスは `sfx-manifest.json` の `credits` と設定パネルに載せる
- `audio/water-ambience.m4a` と `.json`: 環境音のループ。SFX Forge の生成AI（Woosh, Sony AI）で `scripts/water-ambience.sfx.json` から作り、`uv run scripts/build-water-ambience.py` でループにする。Woosh の重みは CC-BY-NC 4.0 のため非商用に限り、画面にクレジットを出す
- `aquarium/customization.json`: 保存キー

### 生態プロファイル

`ecology` には公開情報から調べた泳層・群れ方・採餌・空気呼吸などの傾向を書きます。速度や休止率、行動の頻度は、それらを鑑賞用に表現する調整値で、実測値ではありません。

| 項目 | 内容 |
|---|---|
| `activityPeriod` | `diurnal`（昼行性）/ `crepuscular`（朝夕）/ `nocturnal`（夜行性）。照明に応じて活動量が変わり、昼行性の中層魚は夜に下寄りへ沈んで休む |
| `gait` | `burstCoast`（ひと漕ぎして滑る）/ `steady`（絶えず泳ぐ）/ `glide`（ゆったり漂う）/ `undulate`（体をくねらせる） |
| `speedBodyLengthsPerSec` | 巡航と瞬発の速度（体長/秒）。驚いたときは瞬発で逃げる |
| `restFraction` | 昼間に止まって漂う時間の割合 |
| `depthRange` | 前後方向の居場所（0 = ガラス側、1 = 奥） |
| `social` | 群れ方（`school` / `shoal` / `group` / `solitary`）、仲間との間隔、まとまり、向きのそろい方 |
| `structureAffinity` | 流木や水草に寄る傾向 |
| `habits` | `airBreathing`（水面で息継ぎ）、`bottomRest`（底で休む）、`bottomForage`（底を探る）、`grazing`（ついばむ）、`hideByDay`（活動が落ちる時間に物陰で休む）、`follow`（仲間を追う）、`homeShelter`（決まった種類の住みかの近くで暮らし、ときどき入って休む） |
| `sources` | 根拠にした資料（1件以上必須） |

別種どうしは体が重ならない程度の間合いを取り、小さい魚ほど大きい魚に道を譲ります。

### 描画

泳ぎは魚の画像1枚をメッシュとして変形し、尾の振りと方向転換を描きます（`swim` で魚種ごとに調整）。体のつくりは `swim.bodyPlan` で選びます（性質は `src/core/bodyPlans.ts`、描き方は `src/render/bodyPlans/`）。エビは `swim.bodyPlan: "crustacean"` にすると尾を振らず、脚を前から順に運んで砂底・石・流木の上を歩き、触角（画像の左端から `swim.headStart` まで）を揺らします。驚くと腹を丸めて後ろへ跳ねます。

水景は、背景、泡、生き物と遮蔽（奥行き順）、浮遊物の順で合成し、最後に水の揺らぎ・コースティクス・光の筋・照明の色調を1パスのフィルターでかけます。背景画像は前面ガラスへ cover で敷き、既定では砂底をガラスの下端に合わせます。ガラスが画像よりかなり横長な水槽では、`scene.json` の `framing.plateBottom` で画像のどの高さを下端に合わせるかを決め、砂底だけが映らないようにします（`src/core/plateFraming.ts`。部屋・水槽画面・テストが同じ計算を使う）。

部屋の絵のガラスは実寸より横長なことがあるため、魚の座標の縦の長さは「ガラス越しに見える水の高さ」（横幅とガラスの縦横比から求め、水槽の高さを超えない）にし、縦横の縮尺をそろえます。設定パネルのサイズ表示は水槽の仕様の高さです。

画面は「夜の自然史博物館の展示」を軸に、欧文・数字・学名を Cormorant Garamond、和文の見出しを端末の明朝体で組みます。鑑賞モードでは、描画側がガラスの画面上の位置を `--glass-x/y/w/h` として書き出し、ガラスの縁と照り返し、台への映り込み、水景の色のにじみをその位置に重ねます。

## 保存

`localStorage` の `tropical-aquarium.state.v5.r2` へ、水槽ごとの魚種別匹数・水景・照明、最後に開いた水槽、環境音の音量だけを保存します。魚の位置・性格・驚いた状態は保存せず、再訪時に自然な位置から泳ぎ始めます。

- 水槽ごとの設定は、その水槽のある展示室に初めて入ったときに初期構成で加わります。水槽・魚種・水景を足しても保存キーは変えません。
- 入れられない魚種と上限を超えた匹数は展示室に入るときに、ほかの水槽の水景は読み込み時に落とします。壊れた保存データは水槽ごとに初期値へ戻します。
- 古い形式（v1〜v4、`tropical-aquarium.state.v5`）は移行せずに消します（`src/content/aquarium/customization.json` の `discardedStorageKeys`）。

## 検証

`bun run test` は次を確認します。

- 部屋・水槽・水景・魚種の参照と画像の有無、住みかの種類が水景にあるか、画面と同じ切り取り方で地形がガラス内に収まるか（`content.test.ts`）
- 水槽ごとの魚種と上限、保存データの復元と破損データ
- 泳層・群泳・構造物への接近・方向転換・夜行性・空気呼吸・照明による活動量、住みか、夜の沈み込み、別種との間合い、ガラスを叩いたときの逃げ方と慣れ
- 全水景・上限匹数での昼10分・夜10分の連続遊泳（ガラス内、岩との交差なし、詰まりなし）

全水槽を回す最後の項目（`terrainEndurance.test.ts`）は水槽ごとのテストに分けてあり、8つのプロジェクト（`tanks-1`〜`tanks-8`）で並列に流れます。

| コマンド | 内容 |
|---|---|
| `bun run test` | 全テスト（約30秒）。commit の前に通す |
| `bun run test:fast` | 全水槽を回すテストを除いた速いテスト（約6秒）。作業中に使う |
| `bun run test:tanks -- -t <水槽id>` | 全水槽を回すテストのうち、その水槽だけ |
| `bun run test:fuzz` | 乱数を毎回変えて全テスト。使った値を `TEST_SEED=<値>` と表示するので、落ちたら同じ値を付けて再現する |

テストの間の `Math.random` は決まった乱数列です（`src/core/testSetup.ts`）。同じテストは毎回同じ結果になります。

`bun run verify:webview` は WebKit backend の `Bun.WebView` で、館内図の2段（建物の切り替え、全階の展示室の一覧と縮小版）と展示室への出入り、URLとブラウザの戻る・進む、展示室から水槽への出入り、設定パネル、水槽ごとの生き物と上限、全水景の切替、照明、環境音、隣の水槽への移動、2部屋の行き来、再読込後の復元、展示室に入ったときの保存の補い、ガラスを叩く操作、1440×960・420×912・912×420の表示を確認します。スクリーンショットは `tmp/webview/` に保存します。`--halls=<展示室id>,...` で展示室を絞り、`--changed` でまだ commit していない差分から展示室を選びます（`--changed=<ref>` でその commit からの差分、`--dry-run` で選んだ範囲の表示だけ）。

`bun run plan:check` は、保管庫の展示計画（`catalog/exhibit-plan.json`）とアプリの内容を突き合わせ、食い違いと器の数（建物ごとの展示室・水槽・種）を表示します（[設計](docs/museum-architecture.md#7-展示計画との突き合わせ実装済み)）。`uv run scripts/draft-terrain.py <水景id>` は、水景の絵から地形の下書きと確認画像を作ります（[地形の下書き](docs/terrain-drafting.md)）。

`bun run measure:perf` は描画の重さを測って基準値と比べ、`bun run compare:render -- <前のビルド>` は描画の作りを変えた前後の絵を画素単位で比べます（[性能の計測と基準値](docs/performance.md)）。

### iPhone 表示

部屋の絵と水槽の光は画面の端まで描き、ボタンは安全領域の内側に置きます。左端20pxは Safari の戻るジェスチャー用に透明な領域で覆います。操作部は44px以上です。モーション軽減設定では画面切替のズーム、カメラの漂い、ガラスを叩いたときの波紋を省きます。
