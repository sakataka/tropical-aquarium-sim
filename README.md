# 熱帯魚アクアリウム

明るい自宅のフィッシュルームに並ぶ水槽を選び、リアル寄りの熱帯魚と一枚絵の水景を眺める、個人向けのWebアクアリウムです。飼育ゲームではなく、魚種固有の自然な泳ぎ、手動照明、環境音、観賞モードを中心にしています。

Demo: https://sakataka.github.io/tropical-aquarium-sim/

## 開発

```bash
bun install
bun run dev
bun run test
bun run build
bun run verify:webview
```

## 画面と機能

起動するとフィッシュルームが表示され、並んだ水槽のガラスの中では実際の水景と魚が泳いでいます。水槽を選ぶとカメラが寄り、そのまま水槽を画面いっぱいに眺める鑑賞モードへ入ります。水槽は部屋のガラス越しに見えていたのと同じ切り取り方で映り、画面からはみ出した部分はドラッグ・ホイール・矢印キーで見回せます。鑑賞モードの操作ボタンは、しばらく操作しないと消えます。「設定」で操作パネルを開き（狭い画面では下から）、「閉じて眺める」で鑑賞モードへ戻ります。「部屋に戻る」か Esc で引いてフィッシュルームへ戻ります（設定パネルを開いているときの Esc はパネルを閉じます）。

水槽は、サイズ・水景・入れられる魚種があらかじめ決まった型です。どの魚でもどの水槽に入れられるわけではありません。

| 水槽 | サイズ | 入れられる魚 |
|---|---|---|
| 東南アジアの水草水槽 | 60×36×30cm | ラスボラ・ヘテロモルファ、チェリーバルブ、クーリーローチ、ドワーフグラミー |
| アマゾンの大型水槽 | 90×45×45cm | エンゼルフィッシュ、ネオンテトラ、コリドラス |
| 小型魚のキューブ水槽 | 30×30×30cm | グッピー、プラティ、アカヒレ |

設定パネルでは次の3つを操作します。

- 「魚」: その水槽に入れられる魚種の匹数を、魚種ごと・水槽全体の上限の範囲で変えます。
- 「レイアウト」: その水槽用の一枚絵水景から選びます。
- 「鑑賞設定」: 自然光・クール・夕景・夜景の手動照明と環境音を設定します。

価格、通貨、餌やり、空腹、愛称、お気に入り、飼育ペナルティ、自由ドラッグ配置は持ちません。

水槽や水景はURLで直接開けます。

```text
http://127.0.0.1:5173/?tank=cube-30
http://127.0.0.1:5173/?theme=iwagumi
```

## データとアセット

- `src/content/fish/<species-id>/species.json`: 学名、原産地、体長、泳層、生態プロファイル（`ecology`）と出典
- `src/content/fish/<species-id>/side.png`: 画像生成した横向き魚画像
- `src/content/tanks/<tank-id>/tank.json`: 水槽の名前・分類・サイズ、使える水景、入れられる魚種と上限、最初の魚
- `src/content/room/room.json` と `room.webp`: フィッシュルームの一枚絵（ガラス部分を透過）と、各水槽のガラスの位置
- `src/content/environment/scenes/<scene-id>/scene.json`: 水景名、標準照明、水の色、魚が寄る構造物と泡の出る位置（水槽に対する0〜1の比率）
- `src/content/environment/scenes/<scene-id>/plate.webp`: 画像生成した一枚絵の水景
- `src/content/environment/scenes/<scene-id>/foreground.webp`: 同じ一枚絵から最前面の水草・石だけを切り抜いた透過レイヤー
- `src/content/aquarium/customization.json`: 保存キー

魚種はフォルダへ `species.json` と `side.png` を置くだけで自動読込されます。

`ecology` には公開情報から調べた生態を、体長あたりの速度など実在の単位で書きます。シミュレーションはこの値だけから動きを決めます。

| 項目 | 内容 |
|---|---|
| `activityPeriod` | `diurnal`（昼行性）/ `crepuscular`（朝夕）/ `nocturnal`（夜行性）。照明に応じて活動量が変わる |
| `gait` | `burstCoast`（ひと漕ぎして滑る）/ `steady`（絶えず泳ぐ）/ `glide`（ゆったり漂う）/ `undulate`（体をくねらせる） |
| `speedBodyLengthsPerSec` | 巡航と瞬発の速度（体長/秒） |
| `restFraction` | 昼間に止まって漂う時間の割合 |
| `depthRange` | 前後方向の居場所（0 = ガラス側、1 = 奥） |
| `social` | 群れ方（`school` / `shoal` / `group` / `solitary`）、仲間との間隔、まとまり、向きのそろい方 |
| `structureAffinity` | 流木や水草に寄る傾向 |
| `habits` | `airBreathing`（水面で息継ぎ）、`bottomRest`、`bottomForage`、`grazing`、`hideByDay`、`follow` の組み合わせ |
| `sources` | 根拠にした資料（1件以上必須） |
泳ぎは `side.png` 1枚をメッシュとして変形し、尾の振りと方向転換を描きます。尾の振り方は `species.json` の `swim` で魚種ごとに調整できます。

水景は、背景、泡、奥の魚、前景切り抜き、手前の魚、浮遊物の順で合成し、最後に水の揺らぎ・コースティクス・光の筋・照明の色調を1パスのフィルターでかけます。水景を別々の部品から組み立てず、同じ一枚絵から前景を切り抜くことで、光や影の統一感を保ちます。

## 保存と移行

`localStorage` の `tropical-aquarium.state.v5` へ、水槽ごとの魚種別匹数・水景・照明、最後に開いた水槽、環境音設定だけを保存します。魚の現在座標や速度は保存せず、再訪時に自然な位置から泳ぎ始めます。

v1〜v4 は60cm水槽1つの形式でした。移行時は、魚種をそれを入れられる水槽へ、水景と照明をその水景を持つ水槽へ移します。入れられない魚種や上限を超えた匹数、旧水槽名、個体ID、愛称、お気に入り、空腹などは破棄します。壊れた保存データは水槽ごとに初期値へ戻します。

## 検証

`bun run test` は魚種・水景・水槽のカタログ、水槽ごとの魚種と上限、v1〜v4→v5移行、破損データ、境界・泳層・群泳・構造物への接近、方向転換の頻度、夜行性・空気呼吸・照明による活動量の違いを確認します。

`bun run verify:webview` はWebKit backendの `Bun.WebView` を使い、フィッシュルーム、水槽へ寄って鑑賞モードに入る操作、設定パネルの開閉、水槽ごとの魚と上限、4水景、照明、環境音、部屋へ戻る操作、3水槽の切り替え、再読込後の復元、v4からの移行、420px幅の表示を確認します。スクリーンショットは `tmp/webview/` に保存します。

今後の方針は [開発方向性](docs/development-directions.md) にまとめています。
