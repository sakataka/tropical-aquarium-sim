# 開発方向性

## 現在の方針

このアプリは育成シミュレーションではなく、「リアルな熱帯魚を選び、自分の水景を組み、静かに眺める」鑑賞・コレクション型アクアリウムとして育てます。

主役は常に水槽です。操作は魚、レイアウト、鑑賞設定の3領域に留め、愛称、空腹、餌やり、お気に入り、観察文、設置日数、タップ反応など、世話や個体管理を要求する要素は追加しません。

## 2026年9月の基盤

- 10魚種のカタログ情報を各 `species.json` に統合し、フォルダ単位で自動読込
- 魚を個体データではなく魚種別匹数として保存
- 明るい水草景、自然な流木景、開けた岩組景の3テーマ
- 16点の画像生成アセットと、後景2・中景2・前景3の固定スロット編集
- 背景からガラスまでの奥行きを意識した合成順
- 配置中の中景を魚の受動的な遊泳目標として使用
- 魚種別12匹、水槽全体30匹の上限
- 保存形式v3とv1/v2移行
- 手動照明、環境音、観賞モード
- 1440×960pxと420×912pxのBun.WebView検証

## 次に伸ばす方向

### 魚屋カタログ

追加する魚は、既存の写実寄り2D表現、カメラ方向、光、水中感を揃えます。`species.json` と透明背景の `side.png` を1フォルダに置く構造を維持し、中央集約ファイルや魚種別分岐を増やしません。

種類を増やす際は、検索結果の読みやすさ、原産地域と泳層の偏り、画像の遅延読込、全体30匹での視認性を確認します。価格、通貨、購入シミュレーション、育成条件は対象外です。

### 水景カタログ

背景、底床、水草、流木、石は、既存背景をスタイル参照にして画像生成します。背景・底床以外は透明背景とし、アルファ境界、色かぶり、反転時の不自然さを実際の合成状態で確認します。

自由ドラッグは追加せず、7スロット、表示・非表示、左右反転、アセット定義側の固定位置・倍率という制約を保ちます。テーマは魚種構成を変更しません。

### 自然な鑑賞体験

遊泳は、境界回避、泳層、群泳、キック・惰性・停止、構造物への緩い接近を少数の説明可能なパラメーターで調整します。世話への反応、タップ反応、失敗条件は戻しません。

音と照明は手動で、操作しなくても成立する静かな補助に留めます。自動時刻照明、一時停止、複数水槽管理は当面の対象外です。

### 表示品質と配信サイズ

初回は現在のテーマだけで水槽を成立させ、未使用テーマやカタログ下部の画像は必要になるまで読み込みません。アセット追加時は透過品質とともにPNG/WebP/AVIFの適性、PixiJSのテクスチャ使用量、モバイルでの初回表示を測定します。

## 検証方針

coreはVitest、画面は `bun run verify:webview` のBun.WebViewで検証します。Chrome/Chromium headlessは使いません。

変更時は検索・絞り込み・匹数上限・3テーマ・全スロット・v3復元・照明・環境音・観賞モードを確認し、生成画像を変更した場合はテーマごとの継ぎ目、魚との前後関係、視認性、420px幅の横溢れをスクリーンショットで目視します。
