# 残課題の解消と整理（2026-10-04）

前日の見直し（[第2の部屋と拡張の見直し](review-2026-10-03-second-room.md)）で残した課題を直し、不要な部分を削り、今後の追加に備えて座標や判定を一本化した。

## 方針の変更: ガラスを叩く

「タップ反応は加えない」をやめ、ガラスを指先で軽く叩いたときの驚きを加えた。実際の水槽で誰もが見る反応で、世話や成績ではないため。魚に好き嫌いや記憶は持たせず、得点や罰も付けない。

- 振動は近い魚ほど強く伝わる（水槽の幅の約4割、18〜45cmまで）。前面ガラスを叩くので、手前の魚ほど驚きやすい。
- 逃げ方は魚種名で分けず、習性と体のつくりで決める。住みか（`homeShelter`）を持つ魚はその住みかへ、物陰に隠れる魚（`hideByDay`）は物陰へ瞬発で飛び込み、しばらく様子をうかがってから出る。そのほかの魚は叩いた所から離れる向きへ C 字に急旋回して逃げ、1〜3秒で普段の泳ぎに戻る。エビは向きを変えずに腹を丸め、尾で後ろへ跳ねてから固まる。
- 驚いた後の数秒は警戒し、群れは間隔を詰めてまとまり、採餌や寄り道を始めない。
- 続けて叩くと慣れて反応が弱まり（最小2割）、数十秒で戻る。
- 叩いた所にガラスの小さな波紋を出し、効果音「ボタン」（厚いガラスを軽く叩く音）を鳴らす。モーション軽減設定では波紋を出さない。ドラッグやピンチは叩いた操作に含めない。

## 残課題の解消

- **ガラスの縦横比による縦の潰れ**: 部屋の絵のガラスは実寸より横長なことがあり（アマゾン2.7:1に対し実寸2:1、古代魚4.2:1に対し3.3:1など）、魚の上下の動きと上下の位置が縦に潰れていた。魚の座標の縦の長さを「ガラス越しに見える水の高さ」（横幅÷ガラスの縦横比、水槽の高さが上限）にし、縦横の縮尺をそろえた。設定パネルのサイズ表示は仕様の高さのまま。部屋の絵は描き直していない。
- **前景切り抜き**: 全水景が地形の遮蔽を使うため、未使用の `foreground.webp`（8水景、計1.8MB）と、それを読む描画経路、魚を奥と手前の2層に分ける処理を削除した。旧3水槽の部屋の絵 `room.webp` も削除した（Git の履歴には残る）。地形 `terrain` は必須にした。
- **ニシキテグリとセネガルスの画像**: Codex CLI の画像生成で作り直した。ニシキテグリは青緑の地に縁取りのある橙の迷路模様、セネガルスは小離鰭を10本（実物は8〜11本）にした。プロンプトは [リアリティ改善](realism-2026-10.md) の共通プロンプトに次の指定を加えたもの。
  - ニシキテグリ: base colour is vivid blue-green / turquoise-blue, covered with wavy maze-like orange bands thinner than the blue background, each edged with a fine dark blue line; large rounded pectoral fins; tall first dorsal fin; overall more blue than orange.
  - セネガルス: uniform grey to olive-grey, diamond-shaped ganoid scales, tubular nostrils, exactly ten separate small sail-like dorsal finlets evenly spaced from mid-back to the tail, large fleshy pectoral fins.

## 自然さの修正

- ゼブラダニオを30cmキューブから60cmの東南アジア水槽へ移した（活発に泳ぐ南アジアの魚で、30cmは狭い）。保存済みの匹数は移し先へ引き継ぐ。
- エンゼルフィッシュを単独からゆるい仲間付き（成魚はペアや小群で暮らす）へ。
- 遅い魚が岩と壁の狭いすき間で回り込む向きを決めたまま止まることがあった。0.6秒進めなければ反対側から回り、普段の泳ぎなら行き先も選び直す。

## 整理

- 寄り道先（`structurePoints`）と泡の位置（`bubbleSources`）をガラスに対する比率から背景画像に対する比率へ移し、地形と同じ座標にした。切り取り方（`framing`）や部屋の絵が変わっても位置がずれない。寄り道先はシミュレーションが水景から求める（`plateFraming.ts`）。
- 各ファイルにあった lerp・clamp・ベクトル計算を `core/math.ts` に、習性の検索を `core/habits.ts` にまとめた。
- 使われていない公開関数・再公開をやめ、魚の泳ぎにしか関係しない魚種のエビ用パラメーター（`headStart`）を削った。テストでエビ以外に `headStart` を書けないようにした。
- README を現状に合わせて書き直し、経緯は docs へ寄せた。
