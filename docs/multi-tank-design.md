# 複数水槽とフィッシュルーム 設計

## 目的

いろいろな熱帯魚を眺められるファンタジーと、実在の飼育らしさの間に立つ体験にする。

- 水槽は、水景・水槽サイズ・入れられる魚種があらかじめ決まった「型」として用意する。
- 利用者は、その水槽に入れられる魚種の中から種類と匹数、水景、照明を選ぶ。どの魚でもどの水槽に入れられる、という自由は持たせない。
- 魚種が増えたら、既存の水槽に足すか、新しい型の水槽を増やす。水槽は最大でも10前後を想定する。

## 体験の流れ

1. 起動すると、明るい昼間の自宅フィッシュルームが一枚絵で表示される。
2. 部屋に並ぶ水槽のガラスの中では、その水槽の実際の水景と魚が小さく泳いでいる。
3. 水槽を選ぶと、カメラがその水槽へ寄るように拡大し、ガラスの外側が暗くなっていく。寄り終えた構図は、水槽画面の鑑賞モード（水槽を画面いっぱいに表示）と同じになる。
4. 水槽画面は鑑賞モードと設定モードに分ける。入った直後は鑑賞モードで、「設定」を押したときだけ操作パネルが横（狭い画面では下）から出て、水槽はその分だけ縮む。
5. 「部屋に戻る」か Esc で、逆に引いてフィッシュルームへ戻る。設定パネルを開いているときの Esc はパネルを閉じる。

本物の3D空間は使わない。写真のような質感を保つため、部屋も画像生成した一枚絵とし、拡大の演出で奥行きを出す。

## 最初の3水槽

分類の軸を変えて、違いがはっきりした3つにする。

| id | 名前 | サイズ (cm) | 分類 | 入れられる魚（上限） |
|---|---|---|---|---|
| `amazon-90` | アマゾンの大型水槽 | 90×45×45 | 地域ビオトープ（南米） | エンゼルフィッシュ 4、ネオンテトラ 20、コリドラス 8、ラミーノーズテトラ 16、マーブルハチェット 8 |
| `asia-60` | 東南アジアの水草水槽 | 60×36×30 | 地域ビオトープ（東南・南アジア） | ラスボラ・ヘテロモルファ 12、チェリーバルブ 10、クーリーローチ 6、ドワーフグラミー 2、ミクロラスボラ・ハナビ 12、サイアミーズ・フライングフォックス 2 |
| `cube-30` | 小型魚のキューブ水槽 | 30×30×30 | 丈夫な小型魚の混泳 | グッピー 6、プラティ 4、アカヒレ 10、ゼブラダニオ 6、オトシンクルス 4 |

水槽全体の上限匹数は水槽ごとに持つ（90cm: 40、60cm: 30、30cm: 15）。

今後の候補の例: アフリカ・マラウイ湖の岩組水槽、マングローブの汽水水槽、ベタの単独水槽、ディスカスの高水温水槽。

## データ

### 水槽 `src/content/tanks/<tank-id>/tank.json`

```json
{
  "id": "amazon-90",
  "order": 2,
  "displayName": "アマゾンの大型水槽",
  "category": "地域ビオトープ",
  "description": "…",
  "widthCm": 90,
  "heightCm": 45,
  "depthCm": 45,
  "sceneIds": ["amazon-driftwood", "amazon-planted"],
  "maxTotalFish": 30,
  "species": [
    { "speciesId": "angelfish", "maxCount": 4 },
    { "speciesId": "neon-tetra", "maxCount": 20 },
    { "speciesId": "corydoras", "maxCount": 8 }
  ],
  "defaultStock": [{ "speciesId": "neon-tetra", "count": 10 }]
}
```

- 水景（`scenes/<id>/`）は水槽に属する。プレート画像の縦横比は水槽の前面（幅:高さ）に合わせて生成する。
- 水景の `structurePoints` と `bubbleSources` は水槽サイズに依存しない 0〜1 の比率で持つ。
- 魚種（`fish/<id>/species.json`）は全水槽共通のまま。どの水槽に入れられるかは水槽側が決める。

### フィッシュルーム `src/content/room/room.json`

```json
{
  "aspectRatio": 1.777,
  "tanks": [
    {
      "tankId": "asia-60",
      "glass": { "x": 0.106, "y": 0.313, "width": 0.183, "height": 0.152 },
      "window": { "x": 0.106, "y": 0.313, "width": 0.183, "height": 0.152 }
    }
  ]
}
```

- `room.webp`: 部屋の一枚絵。画像生成ではガラス部分を純粋な緑（#00FF00）で塗ってもらい、その緑を透明に切り抜いて作る。
- `glass`: 画像内の前面ガラスの位置（0〜1 の比率）。魚はこの矩形を水槽の前面として描き、寄るときもこの矩形を画面いっぱいにする。
- `window`: 部屋の絵で透過にした範囲。斜めに見える側面ガラスも含み、水景はここまで広げて描く。
- 水槽を増やすときは部屋の絵を描き直し、`glass` を測り直す。

## 保存形式 v5

```json
{
  "version": 5,
  "activeTankId": "asia-60",
  "tanks": {
    "asia-60": { "stock": [], "layout": { "sceneId": "planted", "lighting": "natural" } }
  },
  "preferences": { "soundEnabled": false, "soundVolume": 0.42 }
}
```

- v4 からの移行: 魚種ごとに、その魚種を入れられる最初の水槽へ移す。v4 の水景を持つ水槽には、その水景と照明を引き継ぐ。
- 入れられない魚種や上限を超えた匹数は、正規化の時点で落とす。

## 描画

- 部屋画面: 1つの PixiJS アプリで、部屋の絵の下に各水槽の水景と魚を描く。魚の動きは水槽画面と同じシミュレーションを使い、状態も共有する（部屋で見ていた魚が、そのまま水槽画面で泳いでいる）。
- 水槽を選ぶと、部屋全体を約0.9秒かけて拡大し、ガラス矩形が画面いっぱいになったところで水槽画面へ切り替える。戻るときは逆の演出にする。
- 水槽画面は、部屋の絵で見えているガラスと同じ縦横比で水景を切り取り（ガラスの形でマスクする）、余白を残して全体が収まる大きさで映す（`render/tankFraming.ts`）。部屋から寄り終えた構図と水槽画面の最初の構図が一致する。そこからホイール・ピンチ・キー・ボタンで近づき、ドラッグや矢印キーで見回す。
- 切り替えの瞬間に2つの画面の絵がそろうよう、次をそろえる: 魚の尾の振りと向きの状態（魚ごとに1つを共有し、隠れている側は進めない）、余白の色（水中フィルターは透明部分を透明のまま残す）、魚まで描き終えてから見せること。
- 水中フィルター・カメラの漂い・泡・浮遊物・操作ボタンは、切り替えが終わってから少しずつ出す。戻るときは水槽画面が消えきってから引き始め、暗幕は引きの大半の時間を使って明ける。
- 魚は水槽の実寸に対する体長で描くため、90cm水槽では60cmより小さく見える。

## 画面の切り替え

- 切り替え中は、次の画面の準備（画像の読み込みと最初の描画）ができるまで前の画面を重ねて残し、準備ができたら0.4秒でフェードして前の画面を外す。
- 重ねている間は、前の画面の魚の動きを止める（同じ魚を2つの画面で二重に進めない）。
- 部屋と水槽画面が一時的に2つの PixiJS アプリとして同時に動くため、破棄は `app.destroy({ removeView: true }, …)` とする。`true` を渡すと全レンダラー共有の資源（作業用テクスチャのプールなど）まで解放され、もう一方の画面が壊れる。
- PixiJS 8.21 の FilterSystem は、最後にフィルターへ渡した共有の作業用テクスチャを内部で参照し続ける。リサイズや破棄の前に空テクスチャへ付け替えて、破棄済みテクスチャを参照する警告を防ぐ。
