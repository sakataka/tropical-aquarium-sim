# 第2の部屋と拡張の見直し（2026-10-03）

対象は `9316ba6..5632fe5`（10月2日夜〜3日）の魚の動き・地形・第2の部屋の追加。動作は `bun run test`・`bun run build`・`bun run verify:webview` とブラウザで確認した。

## 修正した問題

- **サンゴ礁・古代魚の水槽が砂底しか映らない**: 3:2 の生成画像を、横長比3.2〜4.2のガラスへ cover で敷き、砂底をガラス下端に合わせていたため、画像の下35〜47%（砂）だけが映り、魚が砂の上に寝ているように見えた。水景ごとに `framing.plateBottom`（画像のどの高さをガラス下端へ合わせるか）を持たせ、サンゴ礁は0.88、古代魚は0.80にした。水の層、イソギンチャク、流木と岩が映る。
- **2水景の地形が複製のまま**: 経路・回避領域・隠れ場所・構造物がほぼ同じ値で、サンゴ礁に `left-root` が残っていた。画像の輪郭に合わせて作り直した（サンゴ礁: 左右の岩場とイソギンチャクの遮蔽、砂の巣穴、岩の隙間。古代魚: 根張り流木と苔むした岩の遮蔽、根の下と岩陰の隠れ場所）。
- **切り取り計算の重複**: 部屋と水槽画面がそれぞれ画像の配置を計算していた。`core/plateFraming.ts` に一本化し、長時間テストも画面と同じ切り取り方（実際の画像寸法・部屋のガラスの縦横比）で地形を検証する。以前は全水景に同じ仮の枠を使っていた。
- **水槽へ寄る間も部屋の切り替えとサウンドボタンが残る**: 暗くなっていく画面の上に操作が浮いていた。寄り始めたら隠す。
- **部屋の名前の不一致と、部屋IDによる分岐**: 見出しは「フィッシュルーム」、ボタンは「淡水の部屋」で、`id === "freshwater"` / `"special"` の分岐で名前と画像を決めていた。部屋のJSONに `displayName`・`shortName`・`image`・`order` を持たせ、`src/content/room/*.json` を自動で読む。旧3水槽の `room.webp` は配信に含めない。
- **部屋を切り替えると、その部屋の1台目に戻る**: 部屋ごとに最後に見ていた水槽を覚える（保存はしない）。

## 追加した動き

- **住みか `homeShelter`**: 水景の shelter に `kind`（`anemone` / `burrow` / `crevice` / `cave`）を付け、魚種は住む種類と範囲・戻る頻度を持つ。個体ごとに住みかを1か所決め（魚のIDから選ぶので泳ぐ間は変わらない）、泳ぐ先をその周りから選び、ときどき戻って休む。暗い間の隠れ場所にも同じ種類を優先する。同じ隠れ場所に入る仲間は左右へずらして重ねない。魚種名による分岐はない。
- **別種どうしの間合い**: 同じ種の間隔は群れの計算が受け持っていたが、別種は体が重なって素通りしていた。体長の和の半分を間合いにし、小さい魚ほど大きい魚に道を譲る（上下によけやすい）。岩の近くや回り込み中は、隙間で押し合って止まらないよう使わない。3分間のエンゼル3匹とネオン20匹で、体の中心が2cm以内に重なる回数は100回前後から10回未満へ減った。
- **夜の沈み込み**: 昼行性の中層・下層の魚は、夜の照明では生活層の下寄りへ沈んで静かに過ごす。水面に暮らすハチェットなどはそのまま。
- **展示ラベル**: 鑑賞画面の左下に、いま水槽にいる生き物の名前と匹数を添える。博物館の展示ラベルの役割で、個体管理や観察文ではない。

## 拡張のための仕組み

- 魚・水景・水槽・部屋は `src/content/` に置くと自動で読み込む。`content.test.ts` が、部屋に置かれていない水槽、どの水槽にもない魚種や水景、画像の置き忘れ、住みかの種類が足りない水景、画面の切り取りでガラス外へ出る地形と隠れ場所を検出する。手順は [開発方向性](development-directions.md#魚水景水槽を足すときの手順)。

## 残した課題

以下は翌日に対応した。[2026-10-04 の整理](review-2026-10-04.md)。

- 古代魚のガラスは比4.2で、実寸の180×55cm（比3.3）より横長に描かれている。部屋の絵のガラス位置によるもので、直すには部屋の絵の描き直しが要る。
- 全水景が地形の遮蔽を使うため、旧来の前景切り抜き `foreground.webp`（8水景、計1.8MB）は画面では読まれないが、配信物には含まれている。地形のない水景を作る可能性を残すため今回は消していない。
- ニシキテグリの原画は地色が橙寄りで、実物の青緑の地とは少し違う。セネガルスの小離鰭も実物（8〜11本）より多く描かれている。差し替えは画像の生成し直しになるため今回は行っていない。
- タップで驚く・逃げ込む反応は、方針（タップ反応を加えない）に合わせて入れていない。
- iPhone Air 実機での表示と操作は未確認（WebKit 上の420×912で確認）。
