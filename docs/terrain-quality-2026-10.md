# 全13水景の接地・遊泳品質改善

対象は既存5水槽・30魚種・13水景。生成した背景・魚画像、保存済みの水槽ID、匹数、照明を保ち、地形と動きの共通処理を改善する。

## 見た目

- 各 `scene.json` の遮蔽を原画の輪郭に沿う30領域へ見直した。開いた水中、枝の間、前面の砂まで魚を切り落とす領域を除き、日本の石組では前後の石も分けた。
- 表面の目標位置は接地点そのものにする。近づくにつれて描画の支点を口・腹へ移し、離れると通常の支点へ戻す。採餌と休止の切替でも支点を連続させる。
- 採餌魚の口、エビの脚の位置は `swim.mouthAnchor` / `swim.footAnchor` に原画内の比率で定義する。反転・メッシュ変形後の点を補間するため、体格や画面サイズが違っても接地点が合う。
- 姿勢は経路の傾斜へ滑らかに寄せる。エビの触角には個体ごとの固定位相を使い、シミュレーションの乱数更新に伴うちらつきを防ぐ。
- 方向転換のバネを臨界減衰の解析解へ変更し、低fpsでも反転を安定させる。

## 遊泳

- 障害物に対する回り込みの側を保持し、壁に切られた障害物では通れる側を選ぶ。岩へ接触した場合は法線方向の移動を抑え、接線方向へ滑らせる。補正後の速度も実移動に合わせる。
- 8〜22秒間隔で生活層内の奥行き目標を選び、速度を滑らかに変える。群れは近くの同種の前後位置へ緩く寄り、XYの群れ判定にも奥行き距離を含める。
- 深さ方向でも区間を確認し、薄い障害物を飛び越えない。通常の遊泳では遮蔽の輪郭と重なったまま前後関係を切り替えず、輪郭から抜けてから奥行きを変える。
- エビは背景のcover表示で切り取られる経路をガラス内の連続区間へ限定し、切れ目で折り返す。経路上の接地を保ち、ガラス外へ歩き出さない。
- 採餌・休止への到達判定を接地点に近づけ、減速と収束を加えた。昼の隠れ場所からは、夜の照明への切替後に泳ぎ出す。
- 新しい経路・接地・奥行きの状態は実行時だけに持ち、保存形式は変えない。

## 個体の性格

- 生成時の乱数から `FishInstance.personality` を一度だけ作る。速さ（±8%）、反応速度・好む間隔（±15%）、休みやすさ・社交性・寄り道（±20%）を魚種の標準値への倍率として持ち、移動用の乱数が進んでも変えない。
- 同じ魚種でも、泳ぐ速度、曲がる応答、休止の頻度と長さ、群れへの寄り方と間隔、葉や流木への寄り道に小さな違いを出す。群れる魚は、近くで泳ぐ仲間の向きと速さにも緩く合わせる。単独性の魚に群れ行動は加えず、生活層や息継ぎなどの魚種の習性を維持する。
- エビにも歩く速さ、休止、採餌の個体差を適用する。匹数変更では既存個体を維持し、新しい個体だけに性格を作る。水景・照明の切替でも性格は維持する。
- 従来どおり保存対象は匹数と水槽設定。画面を再読み込みすると個体を再生成するため性格も新しくなる。名前や世話の管理画面は追加しない。

## 検証

- `bun run test`：全水景・上限匹数で昼10分と夜10分の連続遊泳を2種類の乱数系列で確認する。個体数、有限値、ガラス内の位置、固体との交差、移動量、通常の奥行き変化、回避中の停止を検証する。
- 回帰テスト：正面からの回り込み、ガラス際の流木から水面への脱出、薄い奥行き障害物、口の接地と離脱、昼夜の隠れ行動、低fpsの反転、触角の位相、採餌から休止への支点切替。
- `bun run build`：TypeScriptの型検証と配信ビルド。
- `bun run verify:webview`：WebKit、1440×960・420×912・912×420で表示・操作・保存復元を確認する。全13水景の切替、5水槽への移動、部屋への復帰、照明・匹数・設定の保持も含める。
- 接地を固定した一時検証画面で全13水景の口・腹・脚と経路を確認する。画像や一時スクリプトは `tmp/quality-refinement/`、通常の画面検証画像は `tmp/webview/` に置き、Git管理しない。

遮蔽と接地経路は画像上の近似形状であり、完全な3Dの表面ではない。物理iPhoneでの確認は別途必要。第2の部屋は次の拡張候補として扱う。
